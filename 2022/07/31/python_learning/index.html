(4). Python mathematical operations

In Python, exponentiation can be represented by two asterisks connecting numbers. For example, the square is [** 2]

This section discusses nested conditional statements (adding another conditional statement within a conditional statement).

Note! Statement A is nested within both Condition 1 and Condition 2. Both must be met!

The same applies to adding an else clause. Both conditions must be met before the statement is triggered.

Python typically uses 4 spaces for indentation. Statements below the if or else clause will be indented to determine which branch they belong to.

Of course, we can also add an else clause to condition 1.

This means that if condition 1 isn’t met, condition 2 won’t be considered, let alone triggering A or B.

Only condition C will be triggered. ↓

**Introduction: There’s also a thing called elif! **It can also be used for nested conditionals.

This structure is simpler and clearer.

However, since Python executes from top to bottom, if both conditions 2 and 3 are met, Python will only execute statement B (condition 2).

Because condition 2 is at the top, once that branch is entered, other conditions at the same level will not be considered!
