Python Sorting Methods

Intro

本文分析三种python排序方式，此部分会在期末考试中出现。

1. Selection

Selection Sort - 选择排序

这种排序方式的逻辑非常直观：每次从未排序的部分中，“选”出最大（或最小）的那个，把它放到正确的位置上。

假设我们讲一个乱序的列表需要从小到大排序，那么Selection Sort的执行过程是这样的：

    1. 遍历整个列表 找到最大的那个数
    2. 将这个最大的数和列表中 最后一个 元素交换位置，这样最大的元素就归位。
    3. 忽略最后一个已经排好的，对剩下的的 N - 1 个数重复上述步骤，直到所有的元素都归位。
  • 说人话就是 挑最大的 放到右侧 找第二大的，放到最大的的左边。

2. Insertion

Insertion Sort - 插入排序

这种排序方式 类似于整理手中的扑克牌。我们假设列表的前半部分已经是排好序的，然后不断把后面的新元素“插入”到前面有序部分的正确位置。

执行过程：

    1. 默认第一个排好
    2. 取第二个 比较大小 看应该放到第一个的前面还是后面
    3. 取第三个 将他和前面两个比较，插入到合适的位置（最前面？中间？最后面？）
    4. 以此类推 直到第 k 步时， 列表的前 k 个元素是有序的。

3. Bubble

Bubble - Sort 冒泡排序🫧

冒泡排序通过重复交换相邻的元素来工作。如果前一个比后一个大，就交换它们。这样，每一轮扫描后，最大的那个元素会像气泡一样“浮”到列表的顶端（末尾）

执行过程：

    1. 从头到尾遍历列表，比较 L[i] 和 L[i + 1]
    2. 如果 L[i] > L[i + 1] 则交换他们
    3. 第一轮结束后 最大的数 会自己“浮”到列表最后面
    4. 重复这个过程 直到完全排序 每一次可以少检查一个（因为每一次排最大的多一个）
算法 (Algorithm) 平均时间复杂度 最好情况 空间复杂度 特点
Selection Sort 无论给什么数据，都要老老实实比完，比较次数固定。
Insertion Sort 如果列表基本有序，它非常快！（Python 的 Timsort 利用了这一点）。
Bubble Sort 教学意义大于实用意义，效率通常最低。

Thinking

Comparison

虽然它们都是 的算法，但“性格”截然不同。

特性 Selection ** Insertion** Bubble
核心动作 寻找 (Find)：每次全场扫描找最大/最小值。 插入 (Insert)：抓一张牌，插到前面有序的牌里。 交换 (Swap)：像鱼吐泡泡一样，邻居之间不断交换。
交换次数 最少 ( 次)。它每一轮只交换一次。 适中。取决于数据乱序的程度。 最多。如果数据倒序，它要疯狂交换。
对有序数据的反应 迟钝。给它一个已经排好序的列表，它还是要傻傻地比完所有次 ()。 敏感 (Smart)。给它一个有序列表，它只需要摸一遍 ()，非常快！ 一般。标准版很慢，优化版可以检测有序并提前停止。
稳定性 (Stability) 不稳定。交换长距离元素时可能会打乱相同元素的相对顺序。 稳定。相同元素不会跨越彼此。 稳定。相邻交换，相同元素不会超车。
