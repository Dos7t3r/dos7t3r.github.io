Intro

Complexity - 复杂度

复杂度的定义 (Definition of Complexity)

  • 什么是复杂度？ 我们不是通过秒表来计时（因为那取决于电脑性能），而是通过计算操作的数量 (Counting Operations) 来衡量算法的效率 。
  • 变量 $n$：通常用来表示输入数据的大小（例如列表的长度 len(L)）
  • 大O符号 (Big-Oh Notation)：写作 $O(g(n))$，用来描述当 $n$ 非常大时，算法运行时间的增长趋势（Growth Rate）。

通常来说，复杂度有下面这四个级别，速度由慢到快排列（N越大，越慢）

1. Quadratic

二次复杂度 (Quadratic) - $O(N^2)$

  • 特征：双重循环 (Nested Loops)。循环套循环，且两个循环的次数都跟 $N$ 有关

  • 外层循环跑 $N$ 次。

    内层循环跑 $N$ 次。

    总次数 ≈ $N \times N = N^2$。

  • 代表算法：冒泡排序 (Bubble Sort)、选择排序 (Selection Sort)、插入排序 (Insertion Sort)。

  • 直观感受：数据量翻倍，时间翻 4 倍。非常慢。

2. Linear

  • 特征：单层循环。代码里有一个循环，随着输入列表长度 $N$ 增加而增加。
  • while index < len(L): 这一行告诉我们循环会执行 $N$ 次。
  • 代表算法：线性查找 (Linear Search)、遍历列表求和。
  • 直观感受：数据量翻倍，时间也翻倍。中规中矩。

3. Logarithmic

  • 特征：循环变量每次是以乘法或除法变化的（例如每次乘以 2，或每次除以 2）。
  • while 2 ** index < len(L):
  • 这意味着 index 每增加 1，覆盖的范围就翻倍。要达到 $N$，只需要 $\log_2 N$ 步。
  • 代表算法：二分查找 (Binary Search)。
  • 直观感受：极快！即使 $N$ 增加一百万倍，时间也只增加几十次操作。

4. Constant

  • 特征：操作次数是固定的，跟输入列表 $L$ 有多长完全没关系。

虽然 $10^{10}$ 是个很大的数字，但它是固定的。不管列表是空还是有一亿个元素，这个循环跑的次数都不变。

  • 代表算法：访问列表的第一个元素 L[0]、计算简单的数学公式。

  • 直观感受：最快，且稳定。
