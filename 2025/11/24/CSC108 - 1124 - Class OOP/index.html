Class & Object

类 (Class) 与 对象 (Object)

  • 类 (Class): 可以理解为一个“模具”或“蓝图”。它定义了一类事物应该具有的数据（属性）和行为（方法）。例如，Student（学生）是一个类。
  • 对象 (Object): 是根据“模具”制造出来的具体实例。例如，“Minerva McGonagall”这个具体的学生就是一个对象。
  • 类比: “物理公式”是类，“带入具体数值计算”是创建对象。

__init__ 与 self

  • __init__ (Initializer): 初始化方法。当你创建一个新对象时，Python 会自动调用这个方法来给对象赋予初始值（比如名字、GPA）。
  • self: 代表“对象自己”。在类的方法中，self.x 意思是“当前这个对象的 x 属性”。

实例创建 (Instantiation) vs 初始化 (Initialization)

Instantiation (实例创建): 为对象分配内存空间（相当于买了一块空地）。

Initialization (初始化): 往分配好的内存里填入具体的值（相当于在空地上盖房子并装修）。

Declaration (声明): 告诉程序有一个特定类型的变量（Python 中通常不需要显式声明类型，但 Java/C++ 需要）。

别名 (Aliasing) [重要难点]

  • 如果你执行 q = p，Python 不会复制一个新的对象，而是让 q 和 p 指向内存中的同一个对象。
  • 后果: 修改 q.x，p.x 也会跟着变，因为它们是同一个东西。这在物理模拟中经常导致 Bug，需要特别小心。

OOP

面向对象编程 (Object-Oriented Programming, OOP)

为什么要用 OOP？ (Motivation)

如果不使用 OOP，存储学生数据会遇到的问题：

  1. Nested Lists (嵌套列表): ['Minerva', 3.9, 1234]。
    • 缺点: 你必须死记硬背索引 0 是名字，1 是 GPA。一旦记错，程序就崩了。
  2. Dictionaries (字典): {'Minerva': {'gpa': 3.9}}。
    • 缺点: 结构变得混乱且难以维护 (Messy and hard to modify)。

OOP 的优势: 代码清晰。你可以直接写 student.name 或 student.cgpa，不用记索引。

Tasks

Task1

题目要求: 创建一个 Student 类，使得我们可以访问 x.name, x.CGPA, x.ID。

Task2

题目要求: 编写函数 passing，返回 CGPA >= grade 的学生列表。

Task3

题目要求: 编写函数 find_student，查找列表中是否存在某名字的学生，返回 True 或 False。
