Stack & frames & Call Stack

1. 定义

1.1 Stack

栈，一种数据结构，特点是FILO（先进后出,First In Last Out），类似一摞盘子，新的盘子上去醉在最上面，而要拿新的也只能从最上面拿。而程序中的stack 用于保存函数的调用过程，每一次调用，都会在最上面（栈顶）压入一个新的stack frame，而执行完成后，就会弹出栈帧，回到上一个函数、

1.2 Call Stack

调用栈，就是程序运行时保存函数调用信息的地方。

1.3 Stack Frame

栈帧 对应于一次函数调用，包括函数的参数、局部变量、返回地址等。
在一个Stack frame中会保存以下内容
- 函数的参数（arguments）
- 函数的局部变量（local variables）

  • 返回地址（return address，执行完返回到哪一行继续）
    所以 stack = 一摞 stack frames，用来追踪程序当前执行的“调用链”。
    举个例子，下面的代码：

他的执行过程：

  1. print(f(3))
    • 压入 print 的栈帧
    • 压入 f 的栈帧（参数 x=3）
  2. f(3) 里调用 g(3)
    • 再压入 g 的栈帧（参数 y=3）
  3. g 运行完 → 弹出 g 的栈帧
  4. f 运行完 → 弹出 f 的栈帧
  5. print 打印完 → 弹出 print 的栈帧
    最终栈里只剩下全局（main）。

上面这些东西的一些性质：

  1. 当程序启动 python解释器自己有一个主程序Stack Frame，就是 _main_ 的frame
  2. 每新增一个函数调用，就是新增一个frame
    (函数调用判断的话 还是不是 函数名+括号(…)的形式，如果有括号，带参数，大概率是调用，但是对于例如 x = 5 这样 y = y + 1 还有循环语句 这样的都不是函数调用~)

为什么要这么写？

  • 字符串不可变（immutable）：不能原地改；所以只能“切片（slice）+ 拼接（concatenate）”生成新串。
  • 切片语法：s[start:stop] 取 从 start 到 stop 之前（右边不包含，exclusive）的子串。
  • 省略 start：s[:-5] 等价 s[0:-5]，都表示“从头取到倒数第 5 个字符之前”。
  • 负索引（negative index）：-1 是最后一个字符，-5 是倒数第 5 个字符的位置。

一些术语对照：
immutable（不可变）、slice（切片）、index（索引）、negative index（负索引）、exclusive（右侧不包含）

2. 易错知识点

2.1 不可以切字符串

Python 的字符串（有引号的）是不可变的 (immutable)，不能直接给某个切片赋值，也不能用减法
如果你写

会报错：TypeError: ‘str’ object does not support item assignment

如果你写

会报错：TypeError: unsupported operand type(s) for -: ‘str’ and ‘str’

2.2 不包括右方括号

切片里，左边的数字 包含，右边的数字 不包含。
右端 不包含：例如 s[a:b] 不含 b 位置字符，别 off-by-one。

2.3 长度不够？

如果 长度不够（比如 n > len(s)），s[:-n] 会是空串，不报错，但结果可能不是你想要的。

2.4 按词语替换 而不是长度

你可以用

s = s.replace('Maybe', 'Perhaps', 1)

（替换一次）

或者

head, tail = s.rsplit(' ', 1); s = head + ' ' + 'Perhaps'

（从最后一个空格切）

2.5 正反怎么不一样？

正向从 0 起，反向从 -1 起
正负相加 = 长度，也就是说：s[i] == s[i - len(s)]

str实例的方法 methods

需要注意的是 有的函数在括号内的参数也可以加入start和end参数，来指定范围，只在这一段内操作。

  • start → 起始位置（包含这个索引）。
  • end → 结束位置（不包含这个索引）。
  • 默认：
    • 如果不写 start，就从 开头 0 开始。
    • 如果不写 end，就到 结尾 len(s)。

⚠️ 注意：end 是 exclusive（右边不包含）。
