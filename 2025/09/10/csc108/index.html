Stack & frames & Call Stack

1. 定义

1.1 Stack

栈，一种数据结构，特点是FILO（先进后出,First In Last Out），类似一摞盘子，新的盘子上去醉在最上面，而要拿新的也只能从最上面拿。而程序中的stack 用于保存函数的调用过程，每一次调用，都会在最上面（栈顶）压入一个新的stack frame，而执行完成后，就会弹出栈帧，回到上一个函数、

1.2 Call Stack

调用栈，就是程序运行时保存函数调用信息的地方。

1.3 Stack Frame

栈帧 对应于一次函数调用，包括函数的参数、局部变量、返回地址等。
在一个Stack frame中会保存以下内容
- 函数的参数（arguments）
- 函数的局部变量（local variables）
- 返回地址（return address，执行完返回到哪一行继续）
所以 stack = 一摞 stack frames，用来追踪程序当前执行的“调用链”。

他的执行过程：

  1. print(f(3))
    • 压入 print 的栈帧
    • 压入 f 的栈帧（参数 x=3）
  2. f(3) 里调用 g(3)
    • 再压入 g 的栈帧（参数 y=3）
  3. g 运行完 → 弹出 g 的栈帧

一些符号 [,],: 的使用

1.使用[,],:进行索引切片操作

Python 的切片 s[start:end] 是「从 start 出发，往右走，直到 end 之前」,就是说 str[start,end,skip]
为什么要这么写？

  • 字符串不可变（immutable）：不能原地改；所以只能“切片（slice）+ 拼接（concatenate）”生成新串。
  • 切片语法：s[start:stop] 取 从 start 到 stop 之前（右边不包含，exclusive）的子串。
  • 省略 start：s[:-5] 等价 s[0:-5]，都表示“从头取到倒数第 5 个字符之前”。
  • 负索引（negative index）：-1 是最后一个字符，-5 是倒数第 5 个字符的位置。

一些术语对照：
immutable（不可变）、slice（切片）、index（索引）、negative index（负索引）、exclusive（右侧不包含）

doctest总结

对于Doctest，总结一下：

  • doctest 是 Python 标准库中的一个模块，它的作用是：把写在 docstring（三引号里的文档字符串） 中的例子拿出来运行，检查结果是否和文档里写的一致。简单理解：文档 + 测试 = doctest。

  • """ """ 里面既可以写说明（文字），也可以写测试（>>> ... 形式的例子）。

  • doctest 只会尝试运行 >>> 开头的代码行，其他文字它不会管。

德摩根定律 De Morgan’s laws

德摩根定律给出“否定（negation）”对**与（conjunction / AND）和或（disjunction / OR）**的分配规则：

  • not (A and B) ≡ (not A) or (not B)

  • not (A or B) ≡ (not A) and (not B)

直观理解：

  • 否定“同时成立”，等价于“至少有一个不成立”；
  • 否定“至少一个成立”，等价于“两个都不成立”。

再直观一点，就是
“一个大括号前面有个‘不是’，可以把它分到括号里，但要把‘和’换成‘或’，‘或’换成‘和’。”
