PSY100 0915 课堂笔记

一、好的研究应具备的要素

  • 理论框架（theoretical framework）：用理论组织观察，提出假设（hypothesis）。
  • 标准化程序（standardized procedure）：除实验操控外，其他环节对所有被试保持一致。
  • 可推广性（generalizability / external validity）：样本具有代表性，结果能外推到现实生活。
  • 客观测量（objective measurement）：指标要有
    • 信度（reliability）：一致性
    • 效度（validity）：测量的就是声称要测的东西

📌 例子：用“考试焦虑量表”去测“社交焦虑”，信度可能不错，但效度不对。

二、常见研究方法

1. 自然观察（naturalistic observation）

  • 优点：真实世界中的自然行为。
  • 缺点：难以控制变量，不能证明因果。

2. 调查/问卷（surveys）

  • 优点：能快速收集大量数据。
  • 缺点：
    • 抽样偏差（sampling bias）
    • 社会称许性偏差（social desirability bias）
    • 反应定势（response sets）

3. 个案研究（case study）

  • 优点：深入、细节丰富，适合稀有情况。
  • 缺点：外推性差，不能断定因果，容易受研究者偏见影响。

📌 课件案例：
Jane（20岁女性），神经性厌食症（AN）治疗中出现强迫症（OCD）症状 → 说明两者可能有重叠，但不能证明因果。

4. 相关研究（correlational research）

  • 相关系数 r：-1 到 +1
    • 正相关（positive）：X↑ Y↑（例：自尊↑ → GPA↑）
    • 负相关（negative）：X↑ Y↓（例：聚会越多 → GPA 越低）
  • 注意：相关 ≠ 因果
    • 方向性问题（directionality problem）：谁导致谁？
    • 第三变量（third variable）：是否有共同影响因素？

📌 案例：

  • 自尊 ↔ GPA，可能受 IQ 影响
  • 吸烟 ↔ 肺癌（不代表必然因果）
  • 吃糖霜玉米片 ↔ 癌症率低（可能只是巧合或第三变量）
  • 台湾避孕使用率 ↔ 家电数量（明显不合理，但数据可能相关）

5. 实验研究（experimental research）

  • 目的：确立因果关系
  • 关键：随机分配（random assignment），确保各组起点一致
  • 控制：
    • 安慰剂效应（placebo effect）
    • 实验者偏差（experimenter bias）
    • 双盲（double-blind）设计

三、常见偏差与控制方法

  • 抽样偏差（sampling bias） → 使用随机/分层抽样
  • 安慰剂效应（placebo effect） → 安慰剂对照组 + 双盲
  • 社会称许性偏差（social desirability bias） → 匿名、使用行为指标
  • 反应定势（response sets） → 变换题型方向、设置注意力检查
  • 实验者偏差（experimenter bias） → 双盲、标准化流程

四、双盲（double-blind）

  • 单盲：参与者不知道分组，研究者知道 → 仍可能有研究者偏差
  • 双盲：参与者和研究者都不知道分组 → 同时避免安慰剂效应和实验者偏差
  • 例子：测试新药是否减轻焦虑，双盲能确保效果来自药物本身，而非心理暗示或研究者影响。

五、学习上的提醒

  • Correlation ≠ Causation → 相关再强也不能直接推因果
  • Random Assignment ≠ Random Sampling
    • 前者：实验里如何分组
    • 后者：从总体里如何抽样
  • 信度（reliability）≠效度（validity） → 两者都要过关
  • 案例不是错误研究 → 它们是“提醒用的教学例子”，用来警示我们避免误解

六、词汇小抄（中英对照）

  • 理论框架 theoretical framework｜假设 hypothesis
  • 标准化程序 standardized procedure｜外部效度 external validity
  • 信度 reliability｜效度 validity
  • 自然观察 naturalistic observation｜问卷/调查 surveys
  • 个案研究 case study｜神经性厌食症 anorexia nervosa (AN)｜强迫症 obsessive-compulsive disorder (OCD)
  • 相关 correlation｜相关系数 correlation coefficient (r)
  • 方向性问题 directionality problem｜第三变量 third variable / confound
  • 实验研究 experimental research｜随机分配 random assignment｜双盲 double-blind
  • 抽样偏差 sampling bias｜安慰剂效应 placebo effect｜社会称许性偏差 social desirability bias｜反应定势 response sets｜实验者偏差 experimenter bias
